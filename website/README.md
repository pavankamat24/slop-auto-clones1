# Panto AI website

Standalone responsive product concept with an interactive sample dashboard and local early-access form. No backend or external product integration is configured. The form saves an email only in the current browser's local storage.

Start from the repository root:

```sh
python3 -m http.server 3000 --directory website --bind 0.0.0.0
```

Open http://localhost:3000. No build or package installation is required. Google Fonts is optional; local font fallbacks work offline.
